# Employee Analytics Dashboard

Employee Analytics Dashboard built with React, Tailwind CSS,Python, FastAPI, and MongoDB. The application provides employee management, analytics, reporting, and export functionalities through an interactive dashboard.

## Features

* Add Employee
* Update Employee
* Delete Employee
* Search Employees
* Department Filter
* Position Filter
* Status Filter
* Pagination
* Dashboard KPI Cards
* Department Overview
* Employee Status Chart
* Position Distribution Chart
* Departments Page
* Reports Page
* Excel Export
* PDF Report Download
* Responsive Modern UI

## Tech Stack

### Frontend

* React
* Tailwind CSS
* Recharts
* Lucide React

### Backend

* FastAPI
* Python

### Database

* MongoDB

### Libraries

* XLSX
* File Saver
* jsPDF
* jsPDF-AutoTable
